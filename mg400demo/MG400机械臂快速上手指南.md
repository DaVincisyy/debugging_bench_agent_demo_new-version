## 一、快速启动流程（5分钟上手）

### 1. 连接机械臂

**有线连接（推荐）：**
1. 网线连接电脑和控制柜的 **LAN1** 口
2. 电脑IP设为 `192.168.1.40`，子网掩码 `255.255.255.0`
3. 打开 **DobotStudio Pro** 软件，选择 MG400，点击"连接"

**无线连接：**
1. 搜索 WiFi `MagicianPro`，密码 `1234567890`
2. 打开软件，选择 MG400，点击"连接"

### 2. 使能机械臂（上电）

连接成功后，顶部工具栏的使能按钮为红色（未使能状态）：
- 点击使能按钮 → 弹出负载设置窗口 → 设置当前末端负载重量
- 确认后机械臂上使能，按钮变为 **绿色**
- 绿色 = 机械臂已就绪，可以运动

### 3. 点动控制

在控制面板中：
- **坐标系模式**：选择用户坐标系/工具坐标系
- **点动/寸动**：点动=按住持续运动，寸动=单击移动固定距离
- 点击 `X+/X-`、`Y+/Y-`、`Z+/Z-`、`R+/R-` 沿笛卡尔坐标移动
- 点击 `J1+~J4-` 沿关节轴旋转

### 4. 运行第一个程序

**图形编程：**
1. 打开"图形编程" → 拖拽积木块
2. 示教点位：点动到目标位置 → 在存点界面"新增"保存点位
3. 示例：拖拽"重复执行"积木，内部放两个"点运动"积木（P1 → P2）
4. 保存 → 点击"开始"运行

**脚本编程（Lua）：**
```lua
-- 在P1和P2之间循环运动
while (true) do
    MovJ(P1)   -- 关节运动到P1
    MovJ(P2)   -- 关节运动到P2
end
```

## 二、硬件与坐标系基础

### 机械臂结构

MG400 是四轴工业机械臂（4个关节：J1~J4）：
- **J1**：底座旋转
- **J2**：大臂
- **J3**：小臂
- **J4**：末端旋转

### 两种坐标表示

| 类型 | 含义 | 示例 |
|------|------|------|
| **关节坐标** | 每个关节的角度（度） | `JointMovJ(0, 0, -90, 0)` |
| **笛卡尔坐标** | 末端在空间的位置(X,Y,Z)和旋转R | `MovJ(473, -141, 469, -180)` |

### 用户坐标系 vs 工具坐标系

- **用户坐标系**（User）：相对于工件/工作台的坐标系，让程序不随工件位置变化而重写
  - 通过两点示教法创建：P0设原点，P1定X轴方向
  - 最多10个，0号=基坐标系
- **工具坐标系**（Tool）：相对于末端工具的坐标系（如焊枪、夹爪）
  - 通过两点示教法：用TCP对准同一点，从两个不同姿态计算偏移
  - 最多10个，0号=法兰坐标系（默认）

## 三、运动指令详解（TCP/IP控制）

通过 **30003端口** 下发运动指令，均为队列指令（排队执行）。

### 关节运动 vs 直线运动

| 指令 | 运动方式 | 适用场景 |
|------|---------|---------|
| `MovJ(x,y,z,r)` | 关节运动（各关节同时到达） | 通用移动，路径不限 |
| `MovL(x,y,z,r)` | 直线运动 | 需要直线路径 |
| `JointMovJ(j1,j2,j3,j4)` | 用关节坐标指定目标 | 精确控制每个关节 |
| `Arc(x1,y1,z1,r1, x2,y2,z2,r2)` | 圆弧运动 | 弧线轨迹 |
| `Circle(count, {P1}, {P2})` | 整圆运动 | 画圆 |

### 运动参数（可选）

```lua
-- SpeedJ/SpeedL: 速度比例 (1~100)
-- AccJ/AccL: 加速度比例 (1~100)
-- CP: 平滑过渡比例 (0~100)
-- User/Tool: 选择坐标系
MovJ(-100, 100, 200, 150, SpeedJ=60, AccJ=50, CP=30)
```

### 相对运动

```lua
RelMovJUser(10, 10, 10, 0, 0)  -- 沿用户坐标系偏移X+10,Y+10,Z+10
RelJointMovJ(10, 0, 0, 0)      -- 关节1偏移10度
```

## 四、远程控制方案

### 方案1：TCP/IP 二次开发（最灵活）

适合：通过自己的程序控制机械臂。

| 端口 | 用途 |
|------|------|
| **29999** | Dashboard指令（设置、使能、获取状态等） |
| **30003** | 运动指令（MovJ/MovL等） |
| **30004** | 实时反馈（8ms间隔，1440字节/包） |
| **30005** | 实时反馈（200ms间隔） |

**基本流程：**
```
1. 连29999端口 → 发送 EnableRobot() 使能
2. 连30003端口 → 发送运动指令
3. 连30004端口 → 接收实时状态反馈
```

**示例指令：**
```
EnableRobot()           -- 使能
MovJ(-100,100,200,150)  -- 运动
GetPose()               -- 获取当前位姿
DisableRobot()          -- 下使能
```

### 方案2：远程I/O模式

适合：通过PLC等外部硬件控制。

1. 在 DobotStudio Pro 中打开"设置 → 远程控制"
2. 选择"远程I/O模式" → 选择工程 → 应用
3. 通过外部 I/O 信号触发启动/停止

### 方案3：远程Modbus模式

适合：需要通过Modbus协议与机械臂通信。

- 通过 LAN2 口（默认IP: 192.168.2.6）连接
- 使用预定义的 Modbus 寄存器地址控制启停、获取状态

## 五、IO与Modbus

### 数字IO

| 指令 | 说明 |
|------|------|
| `DO(index, status)` | 设置数字输出（队列指令） |
| `DOExecute(index, status)` | 立即设置数字输出 |
| `DI(index)` | 读取数字输入状态 |

### Modbus

```lua
-- 创建连接
ModbusCreate("192.168.1.100", 502, 1)
-- 读写寄存器
GetHoldRegs(0, 3095, 1)
SetHoldRegs(0, 3095, 2, {6000, 300}, "U16")
```

## 六、常见问题

### 报警处理
1. 报警图标变为红色 → 点击查看报警详情
2. 使用 `ClearError()` 或点击"清除报警" 
3. 报警清除后用 `Continue()` 恢复运动

### 使能失败
- 检查急停按钮是否被按下（需复位）
- 检查负载设置是否正确
- 检查是否有未清除的报警

### 连接不上
- 确认电脑IP与控制柜IP在同一网段
- 控制柜 LAN1 默认 IP：`192.168.1.6`
- 控制柜 LAN2 默认 IP：`192.168.2.6`

### 机器人状态码（RobotMode）

| 值 | 说明 | 含义 |
|----|------|------|
| 1 | 初始化 | 刚启动 |
| 4 | 未使能 | 需要使能 |
| 5 | 👉 **使能空闲** | 可执行运动指令 |
| 6 | 拖拽模式 | 可手动拖拽示教 |
| 7 | 运行中 | 正在执行运动 |
| 9 | 报警 | 有未清除的报警 |

## 七、完整使用示例

### 示例：TCP/IP控制机械臂往复运动

```python
# Python伪代码示意
import socket

# 1. 连接并使能
dashboard = socket.connect("192.168.1.6", 29999)
dashboard.send("EnableRobot()")
dashboard.send("SpeedFactor(50)")  # 设置速度50%

# 2. 发送运动指令
motion = socket.connect("192.168.1.6", 30003)
motion.send("MovJ(300, 0, 200, 0)")  # 移动到取料点
motion.send("Wait(500)")
motion.send("MovL(300, 0, 50, 0)")   # 直线下降到抓取位置
motion.send("DO(1, 1)")              # 夹爪闭合
motion.send("MovL(300, 0, 200, 0)")
motion.send("MovJ(-300, 0, 200, 0)") # 移动到放料点
motion.send("DO(1, 0)")              # 夹爪张开
```

### 示例：图形编程实现码垛

1. 示教4个点（P1~P4）作为托盘四角
2. 使用"托盘"积木创建行×列的矩阵点位
3. 循环遍历所有托盘点位执行抓取-放置
4. 保存并运行
